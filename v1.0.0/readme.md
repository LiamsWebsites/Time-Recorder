##### **Features:**



###### **Major:**

* Memory Save System
* Temporary Storage Save System
* Temporary Storage to Memory Storage Transfer
* Simple Save Time device
* Personal Best Viewer
* Average Time Viewer
* Numerical Amount for Average Time Viewer
* Error Log for Debugging
* Temporary Storage Clear Button
* Memory Storage Clear Button
* Textarea for directly modifying times using JSON
* JSON file import/export
* File name textbox to customize JSON filename upon export



###### **Minor:**

* Undo button to undo temporary storage saves
* Sound Mixer within Settings
* Clear Text tool for Textarea
* Checkbox to automatically update Textarea on data change
* Checkbox to export files from Textarea rather than storage Save
* Checkbox to automatically transfer time to memory upon time modification
* Draggable balloon and basketball PNGs
